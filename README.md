# Проект Job_search
Учебный проект (Курсовая №2 из Курса Python-разработчик) - "Приложение для поиска вакансий"

## Описание:
Программа для получения информации о вакансиях с платформы hh.ru, сохранения их в базу данных и JSON-файл, 
а также удобной работы с ними: фильтрация, сортировка, удаление и анализ.

## ✨ Ключевые возможности
В данный момент реализовано подключение к API hh.ru (Можно дорабатывать и подключать дополнительные API для поиска вакансий)
Реализовано сохранение вакансий в JSON-файл (Можно добавить работу с фалами других форматов - CSS, txt) и сохранение вакансий в Базу Данных. 
Для учебного проекта 10 компаний по которым собираются и сохраняются вакансии. (Для учебного проекта взято 50 вакансий на каждую компанию)


### 🔍 Работа с JSON:
- Поиск вакансий на hh.ru по профессии и городу
- Фильтрация по зарплате, ключевым словам в названии и описании
- Сохранение результатов в JSON-файл
- Просмотр сохранённых вакансий
- Удаление ненужных вакансий
- Очистка файла
- Топ-N вакансий по зарплате
- Сортировка перед сохранением

### 🗄️ Работа с базой данных PostgreSQL:
- Автоматическое создание и заполнение БД данными о 10 компаниях с hh.ru
- Просмотр статистики по компаниям и количеству вакансий
- Обзор всех компаний с предпросмотром вакансий
- Детальный просмотр всех вакансий выбранной компании
- Расчёт средней зарплаты по всем вакансиям
- Поиск вакансий с зарплатой выше средней
- Поиск вакансий по ключевым словам
- Статистика по компаниям (средняя, медианная, мин/макс зарплата)

# Требования

# Установка
1. Клонируйте репозиторий:

https://github.com/VikaDavlyatshina/Job_search

2. Установите зависимости с помощью Poetry:
```
poetry install
```
3. Настройте базу данных PostgreSQL:

Убедитесь, что PostgreSQL запущен

Создайте файл config.py в корне проекта (или отредактируйте существующий)

Укажите параметры подключения:


## 🛠️ Технические детали

### Архитектура
- **SOLID принципы** - проект соответствует первым двум принципам
- **Абстрактные классы** - для API и работы с файлами
- **Инкапсуляция** - приватные атрибуты и методы
- **Наследование** - классы наследуют абстрактные классы

### Ключевые классы
- `Vacancy` - модель вакансии с методами сравнения
- `HeadHunterAPI` - интеграция с API hh.ru
- `JSONSaver` - сохранение данных в JSON
- `BaseVacancyApi` - абстрактный класс для API
- `DBCreator` - создание и заполнение базы данных 
- `DBManager` - работа с данными в БД


### Используемые технологии
- `Python 3.10+`
- `PostgreSQL + psycopg2`
- `requests - для работы с API`
- `pytest - тестирование`
- `mypy - статическая типизация`
- `flake8 - проверка стиля кода`
- `black - форматирование кода`
- `Poetry - управление зависимостями`
