# Проект Job_search
Учебный проект (Курсовая №2 из Курса Python-разработчик) - "Приложение для поиска вакансий"

## Описание:
Программа, которая будет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и позволять 
удобно работать с ней: добавлять, фильтровать, удалять.

## ✨ Ключевые возможности
В данный момент реализовано подключение к API hh.ru (Можно дорабатывать и подключать дополнительные API для поиска вакансий)
Реализовано сохранение вакансий в JSON-файл (Можно добавить работу с фалами других форматов - CSS, txt)


- 🔍 Поиск вакансий на hh.ru по профессии и городу
- 🎯 Фильтрация по зарплате, навыкам, описанию
- 💾 Сохранение результатов в JSON-файл
- 📋 Просмотр сохранённых вакансий
- 🗑️ Удаление ненужных вакансий
- 📊 Сортировка по зарплате



## 🚀 Установка и запуск:

# Требования
- **Python 3.10+**
- **Poetry (менеджер зависимостей)**

# Установка
1. Клонируйте репозиторий:

https://github.com/VikaDavlyatshina/Job_search

2. Установите зависимости с помощью Poetry:
```
poetry install
```

## Запуск

```bash
python main.py
```

## 🎮 Использование
1. Запустите программу: `python main.py`
2. Выберите "1. Новый поиск"
3. Введите профессию (например: "Python разработчик")
4. Укажите город (например: "Москва")
5. Используйте фильтры для уточнения поиска
6. Сохраните понравившиеся вакансии



## Тестирование

Проект использует `pytest` для написания и выполнения тестов. Чтобы запустить тесты, следуйте инструкциям ниже:

- **В корневой директории проекта выполните команду для запуска всех тестов:**
```bash  
 pytest
 ```
Запуск с проверкой покрытия:
```bash
pytest --cov=src --cov-report=html
```


## 🛠️ Технические детали

### Архитектура
- **SOLID принципы** - проект соответствует первым двум принципам
- **Абстрактные классы** - для API и работы с файлами
- **Инкапсуляция** - приватные атрибуты и методы
- **Наследование** - классы наследуют абстрактные классы

### Ключевые классы
- `Vacancy` - модель вакансии с методами сравнения
- `HeadHunterAPI` - интеграция с API hh.ru
- `JSONSaver` - сохранение данных в JSON
- `BaseVacancyApi` - абстрактный класс для API
